# 异环勤务录

民国老报纸版式的《异环》零氪打卡刊：日课四件 · 周课五件 · 月课三件，同一版面装订三刊。

纯静态、零依赖、无构建——数据存在浏览器 localStorage，不上传任何服务器。

**在线阅读：<https://dachengzi6661.github.io/ananta-duty-ledger/>**

## 用法

- 点条目即勾销，带「笔尖划纸」音效（点刊况栏「音」字小印可开关）
- 勾满日课盖「全勤」章；周课、月课勾满分别盖「周讫」「月讫」
- 周课周一换新，月课每月一号换新；换栏前未勾满不盖印
- 档案仅存本机浏览器，换浏览器或清缓存即失档

## 技术要点

- 原生 HTML / CSS / JavaScript，单页三刊
- 音效用 Web Audio 现场合成（bandpass 噪声两笔），无音频文件
- 字体本地化于 `fonts/`，离线可用
